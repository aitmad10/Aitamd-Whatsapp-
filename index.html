Firebase Realtime Database & WebRTC Configuration

Connect your own Firebase project or inspect the active multi-device signaling backend

1. Live Firebase Realtime Database Connection Active

Paste your Firebase project's firebaseConfig JSON (or just your databaseURL) below to switch immediately to your Firebase Realtime Database, or edit FIREBASE_CONFIG directly inside index.html. When no Firebase URL is configured yet, the app automatically connects over a real multi-device WebSocket Cloud Relay (MQTT over WSS) so cross-device presence, messaging, and WebRTC calling work immediately.

2. Step-by-Step Firebase Setup Instructions

  1. Open the Firebase Console (https://console.firebase.google.com/) and click Add project.
  2. In the left sidebar, go to Build → Realtime Database and click Create Database.
  3. Select your preferred region and start in Test mode, or publish these security rules under the Rules tab: 
    {
  "rules": {
    "users": { ".read": true, ".write": true },
    "chats": { ".read": true, ".write": true },
    "calls": { ".read": true, ".write": true },
    "incomingCalls": { ".read": true, ".write": true }
  }
}
  4. Go to Project Settings → General → Your apps, register a Web App (</>), and copy the firebaseConfig object into FIREBASE_CONFIG inside index.html (or paste it into the box above).
  5. Optional Anonymous Auth: If you restrict rules to auth != null, enable Build → Authentication → Sign-in method → Anonymous. This file automatically calls firebase.auth().signInAnonymously() in the background without asking for OTP, passwords, or names.
